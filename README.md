# AutoCare SaaS - Phần Mềm Quản Lý & Cập Nhật Tình Trạng Xe Ô Tô

Website giới thiệu giải pháp SaaS chuyên dụng dành cho các tiệm sửa chữa ô tô và garage hiện đại. 
- Minh bạch hóa tiến độ sửa chữa 
- Tối ưu quy trình tiếp nhận xe
- Nâng cao trải nghiệm khách hàng.

# Thông tin

đối tượng: chủ garage, kỹ thuật viên, nhân viên chăm sóc khách hàng
mục đích: 
- khách hàng: cập nhật tiến độ trực tuyến, đăng ký/đặt trước gói sữa chữa tại nhà
- nhân viên: sao lưu/cập nhật tình trạng xe, thông báo tiến độ hoàn thành
